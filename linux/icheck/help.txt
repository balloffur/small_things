===================================================================
 icheck — Универсальная утилита сетевой диагностики
===================================================================
Использование: icheck [АРГУМЕНТЫ] [URL/IP]

Если запустить без аргументов (или с -f), выполняется быстрая проверка.
Если передать URL или IP без дефисов (например, icheck google.com),
утилита проверит только эту конкретную цель (Ping + HTTP/HTTPS).

Режимы работы (Профили):
  -f,  -fast       Быстрая проверка: Локальный IP, Публичный IP, пинг Google (По умолчанию)
  -m,  -more       Стандартная проверка: IP, локация, DNS, базовые сайты
  -a,  -all        Полный аудит: Все IP, DNS, проверка всех сайтов из баз + Blacklist

Точечные проверки (можно комбинировать):
  -l,  -local      Показать только локальный IP
  -p,  -public     Показать только публичный IP и локацию
  -d,  -dns        Показать только текущие DNS-серверы
  -bl, -blacklist  Проверить публичный IP в антиспам-базах (DNSBL)
  -proc <имя>      Проверить статус и ресурсы запущенного процесса (напр. icheck -proc vpn)

Модификаторы и настройки:
  -t,  -time       Выводить точное время ответа (Ping и HTTPS)
  -timeout <сек>   Таймаут для сетевых запросов (по умолчанию: 5 сек)
  -4,  -ipv4       Принудительно использовать только IPv4
  -6,  -ipv6       Принудительно использовать только IPv6
  -h,  -help       Показать эту справку

Файлы конфигурации:
  Конфиг (Сайты): ~/.config/icheck/config.conf
  База (Описания): ~/.config/icheck/database.txt
