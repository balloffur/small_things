# small_things

**Личная коллекция компактных header-only утилит на C++17/20**  
(в основном теория чисел, быстрый RNG, случайные графы и простой тайминг)

Всё в одном заголовочном файле — включил и пользуйся.  
Никаких зависимостей кроме STL, никаких сборок, никаких CMake.

Предназначено для:
- быстрого прототипирования
- тестовых вычислений
- соревновательного программирования
- Monte-Carlo / рандомизированных алгоритмов
- экспериментов с простыми числами и графами

Текущая дата последнего обновления описания: февраль 2026

## Подробное описание каждого файла

### primetest_int32.h
Самый компактный и constexpr-дружественный тест простоты для **int32_t**.  
- bitmask до 127  
- trial division до 127  
- Miller-Rabin с базами 2,3,5  
- вручную исключены 4 сильных псевдопростых числа в диапазоне  
→ идеален внутри `constexpr`, шаблонов, метапрограммирования.

### prime_test.h
Полностью **детерминированный** тест простоты для **всего** диапазона uint64_t.  
Использует:
- bitmask до 127  
- trial division малыми простыми  
- Miller-Rabin с **оптимальными** наборами баз в зависимости от размера числа:  
  • < 2³²     → {2,3,61}  
  • < 3.3·10¹⁵ → {2,3,5,7}  
  • < 2⁶⁴     → {2, 325, 9375, 28178, 450775, 9780504, 1795265022}  
→ 0 ложных срабатываний на всём диапазоне.

### factor_int32.hpp
Простая, но достаточно быстрая факторизация 32-битных чисел.  
Алгоритм: малые простые → wheel 6k±1 → Miller-Rabin при необходимости.  
Выводит **все** простые множители (с повторениями) в вектор.

### prime_random.h
Генераторы случайных простых чисел с хорошей плотностью.  
- `random_prime(seed)` — случайное простое ~64 бит  
- `random_prime_digs(digits, seed)` — ровно digits цифр (до 19)  
Использует primorial-фильтр + таблицу кандидатов → обычно простое с 1–3 попыток.

### random_LCG.h — class PRNG64
**Основной** генератор случайных чисел проекта.  
Комбинация LCG + XorShift64 — быстрый, воспроизводимый, удобный API:
- `uint64()`, `uint64(low,high)`, `uint64_exclusive(n)`  
- `uint64_digs(digits)` — ровно N цифр  
- `real()` → [0,1), `real(low,high)`  
- `bit()`, `bit(p)` — biased/unbiased  
- `uint64_cond(predicate, max_tries)`  
- `time_seed()` — засев от часов  
Поддержка C++20 concepts (опционально).

### graph.h — struct Graph
Простейшая реализация графа через **матрицу смежности**.  
Поддерживает:
- неориентированные / ориентированные  
- взвешенные / невзвешенные  
- add/remove edge/vertex, swap, pop  
- degree / weight (in/out)  
- print()  
→ удобно для n ≤ 3000–4000.

### rgraph.h
Много разных генераторов случайных графов:
- `random_graph(n,p,seed)` — G(n,p) undirected unweighted  
- `random_graph_w(…, low,high)` — взвешенный  
- `random_graph_o(…)` / `random_graph_o_w(…)` — directed  
- `random_graph_c(…)` / `random_graph_w_c(…)` — **связные** (через random spanning tree)  
- `random_tree(n,RNG)` / `random_tree_w(…,low,high)` — uniform labeled trees (Prüfer)  
- `random_graph_o_c(…)` — directed weakly connected  

### timing.h
Два простых инструмента:
1. `time_code()` — toggle: первый вызов — старт, второй — стоп + печать ms/us/ns  
2. `time_labels::time_label` — класс для усреднения по многим итерациям (`time()`, `average()`, `reset()`)

## Пример типичного использования

```cpp
#include "random_LCG.h"
#include "prime_test.h"
#include "rgraph.h"
#include "timing.h"

int main() {
    auto rng = PRNG64::time_seed();

    // случайное простое ~18 цифр
    uint64_t prime = random_prime_digs(18, rng.uint64());
    printf("Prime: %llu → %s\n", prime, is_prime(prime) ? "yes" : "no");

    // связный взвешенный граф 200 вершин
    Graph g = random_graph_w_c(200, 0.07, rng.uint64(), 1, 100);
    g.print();

    time_code();
    // ... какой-нибудь долгий код ...
    time_code();  // → печатает время

    return 0;
}

**random_graph_generator.cpp**  
→ отдельная компилируемая утилита, которая умеет генерировать случайные графы по параметрам и сохранять их в текстовый файл (матрица смежности)



### Примеры запуска

```bash
# Один связный невзвешенный граф 50–120 вершин
g++ -std=c++17 -O2 random_graph_generator.cpp -o gen

## Random Graph Generator

Утилита `random_graph_generator` предназначена для генерации случайных графов и сохранения их в файл в виде матрицы смежности.

Генератор поддерживает:

* ориентированные и неориентированные графы
* связные (для неориентированных) и слабо связные (для ориентированных) графы
* сильно связные ориентированные графы
* взвешенные графы с целочисленными весами
* генерацию нескольких графов за один запуск

---

### Файлы и зависимости

Добавленный в проект файл:

* `random_graph_generator.cpp`

Для корректной сборки и работы программы необходимо наличие следующих компонентов проекта:

* `rgraph.h`
* Структура `Graph`, содержащая:

  * `int size`
  * `matrix` — матрица смежности
* Генератор случайных чисел `PRNG64`, который должен поддерживать:

  * `PRNG64(double seed)`
  * `static PRNG64 time_seed()`
  * `int64(low, high)`
  * `real(low, high)` и `real()`
* Реализации функций генерации графов:

  * `random_graph`, `random_graph_c`
  * `random_graph_w`, `random_graph_w_c`
  * `random_graph_o`, `random_graph_o_c`, `random_graph_o_sc`
  * `random_graph_o_w`, `random_graph_o_w_c`, `random_graph_o_w_sc`

При отсутствии любого из перечисленных элементов проект не соберётся.

### Запуск программы

```bash
./random_graph_generator [параметры]
```

При запуске без параметров или при использовании флага `-h` выводится справка по доступным аргументам командной строки.

---

### Параметры командной строки

* `-t <count>`
  Количество графов для генерации.
  По умолчанию: `1`

* `-n <low> <high>`
  Диапазон количества вершин графа. Реальное значение `n` выбирается случайно из указанного диапазона.
  По умолчанию: `0 100`

* `-p <low> <high>`
  Диапазон вероятности существования ребра. Значение `p` выбирается случайно.
  По умолчанию: `0 1`

* `-v <low> <high>`
  Включает режим взвешенного графа и задаёт диапазон целочисленных весов рёбер.

* `-o`
  Генерация ориентированного (directed) графа.
  По умолчанию граф неориентированный.

* `-c`
  Для неориентированного графа — генерация связного графа.
  Для ориентированного графа — генерация слабо связного графа.

* `-sc`
  Генерация сильно связного ориентированного графа. Автоматически включает `-o`.

* `-s <seed>`
  Seed для генератора случайных чисел. Значение `0` означает использование seed по времени.
  По умолчанию: `0`

* `-f <file_name>`
  Имя выходного файла.
  По умолчанию: `graph.txt`

* `-h`
  Вывод справки.

---

### Формат выходных данных

Результат работы программы записывается в текстовый файл (по умолчанию `graph.txt`).

Вывод осуществляется в виде матрицы смежности размера `n × n`.

Если количество графов `t > 1`, формат файла следующий:

* первая строка содержит число `t`
* далее подряд записываются `t` матриц смежности
* для каждого графа значение `n` выбирается независимо

Пример (один граф, `n = 3`):

```
0 1 0
1 0 1
0 1 0
```

Значения в матрице выводятся напрямую из `G.matrix[r][c]` и зависят от типа графа (ориентированный, взвешенный и т.д.).

### Примеры использования

Сгенерировать один неориентированный граф:

```bash
./random_graph_generator -n 10 20 -p 0.1 0.3
```

Сгенерировать ориентированный слабо связный граф:

```bash
./random_graph_generator -o -c -n 30 30 -p 0.05 0.05
```

Сгенерировать ориентированный сильно связный граф:

```bash
./random_graph_generator -sc -n 50 50 -p 0.1 0.1
```

Сгенерировать взвешенный граф с весами от 1 до 9:

```bash
./random_graph_generator -v 1 9 -n 20 20 -p 0.2 0.2
```

Сгенерировать 5 графов за один запуск:

```bash
./random_graph_generator -t 5 -n 10 15 -p 0.1 0.4
```

---

### Замечания

Параметр `-f` задаёт имя выходного файла. Для его корректной работы необходимо открывать файл с использованием переданного имени, а не жёстко заданной строки.
