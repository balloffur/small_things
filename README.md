# small_things

**Личная коллекция компактных header-only утилит на C++17/20**  
(в основном теория чисел, быстрый RNG, случайные графы и простой тайминг)

Всё — в одном заголовочном файле: подключил и используешь.  
Никаких сторонних зависимостей, кроме STL. Никаких систем сборки, никаких CMake.

Проект предназначен для:
- быстрого прототипирования алгоритмов
- тестовых и учебных вычислений
- соревновательного программирования
- Monte-Carlo и рандомизированных алгоритмов
- экспериментов с простыми числами и графами

*Дата последнего обновления описания: февраль 2026*

## Краткое описание файлов

### `primetest_int32.h`
Минималистичный `constexpr`-дружественный тест простоты для `int32_t`:
- bitmask + trial division
- Miller–Rabin (2,3,5)
- вручную убраны сильные псевдопростые

Идеален для compile-time и шаблонного кода.

### `prime_test.h`
Полностью **детерминированный** тест простоты для всего диапазона `uint64_t`.
Использует оптимальные наборы баз Miller–Rabin:
- < 2³² → {2,3,61}
- < 3.3·10¹⁵ → {2,3,5,7}
- < 2⁶⁴ → {2, 325, 9375, 28178, 450775, 9780504, 1795265022}

Гарантирует 0 ложных срабатываний.

### `factor_int32.hpp`
Факторизация 32-битных чисел:
- малые простые
- wheel 6k±1
- Miller–Rabin при необходимости

Возвращает *все* множители (с кратностями).

### `prime_random.h`
Генерация случайных простых чисел:
- `random_prime()` — ~64 бита
- `random_prime_digs(digits)` — ровно N десятичных цифр (≤ 19)

Использует primorial-фильтр → обычно простое за 1–3 попытки.

### `random_LCG.h` — `class PRNG64`
Главный генератор случайных чисел проекта.  
Комбинация LCG + XorShift64:
- `uint64()`, `uint64(low, high)`
- `uint64_digs(digits)`
- `real()`, `real(low, high)`
- `bit()`, `bit(p)`
- `uint64_cond(predicate)`
- `time_seed()`

Быстрый, воспроизводимый, удобен для алгоритмов.

### `graph.h` — `struct Graph`
Простейший граф на матрице смежности:
- ориентированный / неориентированный
- взвешенный / невзвешенный
- add/remove edge и vertex
- степени вершин, печать

Подходит для n ≲ 3000–4000.

### `rgraph.h`
Набор генераторов случайных графов:
- Erdős–Rényi `G(n,p)`
- взвешенные версии
- ориентированные версии
- связные и слабо связные графы
- равномерные деревья (Prüfer)

Используется для тестирования графовых алгоритмов.

### `timing.h`
Минимальный тайминг:
- `time_code()` — старт/стоп с печатью
- `time_label` — усреднение по сериям

## Пример использования

```cpp
#include "random_LCG.h"
#include "prime_test.h"
#include "rgraph.h"
#include "timing.h"

int main() {
    auto rng = PRNG64::time_seed();

    uint64_t p = random_prime_digs(18, rng.uint64());
    printf("prime = %llu → %s\n", p, is_prime(p) ? "yes" : "no");

    Graph g = random_graph_w_c(200, 0.07, rng.uint64(), 1, 100);
    g.print();

    time_code();
    // ... код ...
    time_code();
}
```

## Программа генерации случайных графов

**`random_graph_generator.cpp`** — отдельная консольная утилита поверх `rgraph.h`, предназначенная для генерации случайных графов по параметрам командной строки и сохранения их в текстовый файл в виде матрицы смежности.

### Возможности
- ориентированные и неориентированные графы
- связные и слабо связные графы
- сильно связные ориентированные графы
- взвешенные и невзвешенные графы
- генерация нескольких графов за один запуск

### Параметры

- `-t <count>` — количество графов (по умолчанию 1)
- `-n <low> <high>` — диапазон числа вершин
- `-p <low> <high>` — диапазон вероятности ребра
- `-v <low> <high>` — включить веса рёбер
- `-o` — ориентированный граф
- `-c` — связный / слабо связный
- `-sc` — сильно связный ориентированный
- `-s <seed>` — seed (`0` → по времени)
- `-f <file>` — имя выходного файла
- `-h` — справка

### Формат вывода

Выходной файл содержит матрицу смежности `n × n`.

Если `t > 1`, первая строка — число графов `t`, далее подряд идут соответствующие матрицы (для каждого графа `n` выбирается независимо).

---

### Примеры

```bash
# Один связный граф
./gen -c -n 50 120 -p 0.05 0.25

# 10 сильно связных ориентированных взвешенных графов
./gen -t 10 -sc -n 150 350 -p 0.02 0.15 -v 1 1000 -f big.txt

# Воспроизводимая генерация
./gen -t 3 -n 30 60 -p 0.1 0.3 -s 123456
```
